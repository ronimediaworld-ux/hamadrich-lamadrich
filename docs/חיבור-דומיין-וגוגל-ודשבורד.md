# חיבור הדומיין, גוגל והדשבורד — המדריך למדריך

מה כבר קיים באתר ומוכן: דף ניהול ב-`/admin` (עריכת תוכן, סטטיסטיקות, תגובות, הצעות ונרשמים), sitemap.xml ו-robots.txt, כותרות ותיאורים לכל עמוד, canonical, ו-JSON-LD.
מה חסר ובידיים שלך: לקנות דומיין, לחבר אותו, ולהדביק כמה ערכים ב-Render.

## שלב 1: קניית דומיין (רק את יכולה לשלם)
- סיומת מומלצת: **co.il** (קהל ישראלי). צריך רשם מורשה על ידי איגוד האינטרנט הישראלי (רשימה ב-isoc.org.il). אפשר גם **com**.
- שמות לבדיקה: hamadrich.co.il, lamadrich.co.il, hamadrich-lamadrich.co.il (לבדוק זמינות ברשם).
- לפני תשלום לבדוק: מחיר חידוש (לא רק מחיר ראשון), ושאפשר לערוך רשומות DNS.

## שלב 2: חיבור הדומיין ל-Render
1. Render → השירות hamadrich-lamadrich → Settings → Custom Domains → Add Custom Domain. מוסיפים גם `example.co.il` וגם `www.example.co.il`.
2. אצל הרשם (או ב-DNS) מוסיפים את מה ש-Render מציג:
   - ל-www: רשומת CNAME שמצביעה ל-`hamadrich-lamadrich.onrender.com`.
   - לדומיין הראשי (בלי www): רשומת ALIAS/ANAME, או A לפי מה ש-Render מציג. אם הרשם לא תומך, אפשר להעביר את ה-DNS ל-Cloudflare (חינם) ולהגדיר CNAME במצב "DNS only".
3. לחצו Verify ב-Render. אישור ה-HTTPS נוצר אוטומטית (עד כמה דקות עד שעות).

## שלב 3: להגיד לאתר מה הכתובת החדשה (Render → Environment)
- `SITE_URL` = `https://example.co.il` (הכתובת האמיתית שלכם)
- `FORCE_CANONICAL_HOST` = `true` (כל כניסה דרך onrender.com או www תעבור לכתובת הראשית, כדי שגוגל יראה אתר אחד)
- להפעיל רק אחרי שהדומיין כבר עובד!

## שלב 4: גוגל (Search Console)
1. https://search.google.com/search-console → Add property.
2. אפשרות א׳ (מומלצת): **Domain**, מדביקים רשומת TXT ב-DNS.
   אפשרות ב׳: **URL prefix** עם `https://example.co.il`, אימות "HTML tag": מעתיקים את הערך מתוך `content="..."` ושמים ב-Render כ-`GOOGLE_SITE_VERIFICATION`.
3. אחרי האימות: Sitemaps → מוסיפים `sitemap.xml`.
4. אפשר לבקש אינדוקס לעמוד הבית (URL Inspection → Request indexing). גוגל מטפל בשאר לבד, ולוקח זמן מכמה ימים לכמה שבועות.

## שלב 5: דשבורד לעריכה ישירה וקבלת מידע (`/admin`)
הכניסה בסיסמה (`ADMIN_PASSWORD` שכבר מוגדר). בראש הדף יש רשימה "מצב המערכת" עם וי ירוק על מה שמוגדר.
כדי שעריכה מהדשבורד תעלה לאתר בעצמה, מוסיפים ב-Render:
- `GITHUB_TOKEN`: טוקן של GitHub (Fine-grained) לחשבון ronimediaworld-ux, גישה רק למאגר hamadrich-lamadrich, הרשאה Contents: Read and write.
- `RENDER_DEPLOY_HOOK`: Render → Settings → Deploy Hook (מעתיקים את הקישור). אחרי כל שמירה מהדשבורד האתר יתעדכן לבד בעוד כשתי דקות.
- (אופציונלי) מייל על הצעות ותגובות חדשות: `RESEND_API_KEY` ו-`NOTIFY_EMAIL`.
- (אם עוד לא) `UPSTASH_REDIS_REST_URL` ו-`UPSTASH_REDIS_REST_TOKEN`, כדי שצפיות ותגובות לא יימחקו.

טוקנים וסיסמאות מדביקים בעצמכם. הם לא נשמרים בקוד.
